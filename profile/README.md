**Ditulis dulu, baru dibuat.**

Daluang adalah konsultan software di Indonesia. Kami menulis kebutuhan bersama Anda, membuat software-nya, lalu merawatnya.

## Karya

| Produk | Isi | Status |
|---|---|---|
| DaluangPOS | POS untuk warung, tetap jalan tanpa internet | Dalam pengembangan |
| [Daluang CMS](https://github.com/rimzzlabs/daluang) | CMS Markdown di Cloudflare Workers, open source | Dalam pengembangan |

## Cara kerja

1. **Tulis dulu, baru buat.** Keputusan dan kebutuhan ditulis dan disetujui sebelum ada kode.
2. **Sesederhana kertas.** Software harus bisa dipakai tanpa pelatihan panjang.
3. **Tahan lama.** Software harus bisa dirawat bertahun-tahun, dan data tidak boleh hilang.
4. **Jujur soal batas.** Kami bilang apa yang bisa dikerjakan, apa yang tidak, dan berapa lama.

## Nama

Daluang adalah kata Sunda untuk kertas kulit kayu yang dipakai untuk menulis naskah. Tanda kami adalah huruf D yang digambar sebagai selembar kertas dengan sudut terlipat.

Panduan identitas ada di [`brand/`](https://github.com/daluangsoftware/.github/tree/HEAD/brand).
